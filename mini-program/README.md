# 微信小程序端（任务4）

本目录是认知筛查系统的小程序端，用于患者管理、量表选择、测评录入、结果查看、报告下载和离线暂存演示。

## 已实现

- 登录页和会话保存；
- 患者列表、患者详情和患者新增；
- 量表列表、量表说明和测评录入；
- 测评完成页、结果页、综合报告页；
- 测评记录和报告下载入口；
- 离线暂存与同步页面；
- 自定义底部导航。

## 运行方式

1. 打开微信开发者工具；
2. 选择“导入项目”；
3. 项目目录选择本仓库的 `mini-program`；
4. AppID 使用 `project.config.json` 中配置的 AppID，或按课程演示需要选择测试号；
5. 点击“编译”运行。

## 后端地址

默认后端地址配置在 `app.js`：

```text
https://adscdbackend-311006-10-1479821149.sh.run.tcloudbase.com/api/v1
```

本地调试时可以临时改为：

```text
http://localhost:3000/api/v1
```

小程序请求会自动携带本地保存的 Bearer Token。登录成功后，患者、量表、测评和报告页面会调用后端真实接口。

## 注意事项

- 不要在代码中提交真实账号密码、JWT、SecretId、SecretKey 或患者隐私信息；
- `project.private.config.json` 只包含开发者工具本地偏好，正式协作时以 `project.config.json` 为准；
- 若微信开发者工具开启合法域名校验，需要在小程序后台加入后端域名，课程演示可按老师要求使用“不校验合法域名”调试。
