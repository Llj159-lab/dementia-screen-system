## 1. 项目概述

本项目基于 6 个 PDF 量表原始资料，从零构建一套**认知障碍评估量表的数据库与评分引擎**。
系统对 6 个常用认知/情绪筛查量表进行标准化配置与统一计分：

| 量表编码 | 中文名 | 计分类型 | 满分 |
|---|---|---|---|
| `SCD_Q9` | 主观认知下降自测表（SCD-Q9） | 累加（SUM） | 9 |
| `GDS` | 老年抑郁量表（GDS-15） | 累加（SUM，含反序） | 15 |
| `FAQ` | 功能活动问卷（FAQ） | 累加（SUM，含 NA） | 30 |
| `MMSE` | 简明精神状态检查 | 分项（ITEMIZED，教育界值） | 30 |
| `MOCA_B` | 蒙特利尔认知评估基础量表（MoCA-B） | 分项（ITEMIZED，教育界值） | 30 |
| `CDR` | 临床痴呆评定量表（CDR） | 复杂（CDR，Morris 规则） | 3（整体）/ 18（CDR-SB） |

系统核心目标：

1. **数据与逻辑分离**：题目、选项、分值、界值、指导语等**数据**入库；
   累加、反序、分项、CDR 规则等**逻辑**入代码。
2. **单一数据源**：`scoring/config_data.py` 是配置数据的唯一权威来源，
   评分引擎与数据库种子数据均由它派生，保证**库表与代码一致**。
3. **计分逻辑唯一**：全系统只暴露一个评分入口 `score()`，
   杜绝“同一量表多处各写一套算法”导致的计分不一致。

## 4. 数据库设计

### 4.1 设计总览

共 **8 张表**：5 张核心表 + 3 张量表配置支撑表。

- **核心表**（承载业务主数据）
  1. `sys_user`（用户表）
  2. `patient`（患者表）
  3. `scale`（量表配置表）
  4. `assessment`（测评主记录表）
  5. `assessment_detail`（测评详情表）
- **支撑表**（承载“题目/选项/分值/界值”配置，满足“录入全部配置数据到数据库”的要求）
  6. `scale_item`（量表题目表）
  7. `scale_option`（量表选项表）
  8. `scale_cutoff`（量表界值表）

### 4.2 实体关系（ER）

```
sys_user 1 ──── N assessment N ──── 1 scale
                 │
                 │ 1
                 │
                 N
          assessment_detail N ──── 1 scale_item N ──── 1 scale
                                       │
                                       │ 1
                                       N
                                 scale_option

patient 1 ──── N assessment
scale   1 ──── N scale_cutoff
```

主要关联：

| 关联 | 基数 | 外键 |
|---|---|---|
| 患者 ↔ 测评 | 1 : N | `assessment.patient_id → patient.id` |
| 量表 ↔ 测评 | 1 : N | `assessment.scale_id → scale.id` |
| 用户 ↔ 测评（测评者） | 1 : N | `assessment.assessor_id → sys_user.id` |
| 量表 ↔ 题目 | 1 : N | `scale_item.scale_id → scale.id` |
| 题目 ↔ 选项 | 1 : N | `scale_option.item_id → scale_item.id` |
| 量表 ↔ 界值 | 1 : N | `scale_cutoff.scale_id → scale.id` |
| 测评 ↔ 详情 | 1 : N | `assessment_detail.assessment_id → assessment.id` |
| 题目 ↔ 详情 | 1 : N | `assessment_detail.item_id → scale_item.id` |

### 4.4 支撑表字段说明

#### ⑥ `scale_item`（量表题目表）

`id`、`scale_id(FK)`、`item_code(量内唯一, 如 MMSE_01)`、`item_no(题号)`、
`domain(认知域/分项)`、`item_text(TEXT 题干)`、`item_type(单选/…)`、
`score_method(DIRECT/SPECIAL)`、`max_score`、`required(是否必答)`、`sort_order`、`remark`。

#### ⑦ `scale_option`（量表选项表）

`id`、`item_id(FK)`、`option_code`、`option_text`、`score_value(DECIMAL 分值)`、
`is_na(TINYINT 是否 NA 不计分)`、`sort_order`。

> **反序计分**（如 GDS 反序题）直接体现在 `score_value`：反序题「是」记 0、「否」记 1，
> 从而累加量表统一用“选项分值求和”实现，无需在代码里写反向判断。

#### ⑧ `scale_cutoff`（量表界值表）

`id`、`scale_id(FK)`、`cutoff_type(EDUCATION/LEVEL)`、`group_key(分组键)`、
`result_label(解释文字)`、`is_abnormal(TINYINT)`、
`edu_years_min/max(教育年限区间，EDUCATION 用)`、
`min_score/max_score(总分区间，LEVEL 用)`、
`threshold(界值分，EDUCATION 用)`、`sort_order`。

- **EDUCATION 型**：承载 MMSE / MoCA-B 的教育界值；按 `[edu_years_min, edu_years_max]` 匹配；
  得分 `≤ threshold` 判异常。
- **LEVEL 型**：承载 GDS 分级、FAQ 分级；按 `[min_score, max_score]` 匹配 `result_label`。

## 5. 评分引擎设计

### 5.1 设计原则

1. **数据在库、逻辑在码**：题目 / 选项 / 分值 / 界值 / 指导语存数据库；
   累加 / 反序 / 分项 / CDR 规则在代码。
2. **单一数据源**：`scoring/config_data.py` 是唯一权威来源；
   - 评分引擎直接消费它（离线可跑、测试可跑）；
   - `scripts/generate_seed_sql.py` 依据它生成 `sql/02_seed_data.sql`；
   - `db/loader.py` 从数据库反序列化出**相同结构**的 `ScaleConfig`。
3. **计分逻辑唯一**：全系统只通过 `scoring.engine.score` 计分，各量表实现
   `validate / compute_raw / apply_cutoff` 三个方法，由基类统一调度。

### 5.2 统一入口

```python
from scoring import score

def score(scale_code: str,
          answers: dict,
          patient: dict | None = None,
          config: ScaleConfig | None = None) -> ScoreResult
```

- `scale_code`：`SCD_Q9 / GDS / FAQ / MMSE / MOCA_B / CDR`（大小写不敏感）。
- `answers`：作答字典，形如 `{"MMSE_01": "1", "GDS_05": "否", "CDR_MEMORY": "1.0"}`。
  值可以是**选项编码**或**选项文本**（优先按编码匹配）。
- `patient`：患者上下文；MMSE / MoCA-B 需 `{"education_years": 9}`。
- `config`：可选，显式传入的量表配置（如 `db.loader.load_scale_config` 结果）；
  缺省用内置配置。
- 返回 `ScoreResult`：

```python
ScoreResult(
    scale_code, scale_name, total_score, sub_scores, item_scores,
    result_label, cutoff_group, cutoff_value, is_abnormal, extra,
)
```

`ScoreResult` 关键字段：

| 字段 | 说明 |
|---|---|
| `total_score` | 总分 |
| `sub_scores` | 分项得分（按认知域，`dict`） |
| `item_scores` | 逐题得分（`list[ItemScore]`） |
| `result_label` | 解释结果（“正常”/“轻度抑郁”/“CDR=1”…） |
| `cutoff_group` / `cutoff_value` | 匹配到的界值分组 / 界值 |
| `is_abnormal` | 是否异常（`bool` 或 `None`） |
| `extra` | 附加信息（如 CDR 的 `cdr_sb`） |

### 5.3 评分流程（基类调度）

```
score()
  ├─ validate(answers, patient)         # 必答校验 + 选项匹配校验
  ├─ compute_raw(answers, patient)      # → (total, sub_scores, item_scores)
  ├─ apply_cutoff(total, patient)       # → (group, value, label, is_abnormal)
  └─ extra_info(total, sub_scores, ...) # → extra（CDR-SB 等）
```

- `BaseScale`（累加类，SUM）：`compute_raw` 逐题匹配选项、累加分值、按 `domain` 汇总；
  `apply_cutoff` 按 LEVEL 分级区间匹配。
- `EducationScale`（分项类，ITEMIZED）：继承累加，覆写 `apply_cutoff` 为
  “按 `education_years` 匹配教育界值 → `total ≤ threshold` 判异常”。
- `Cdr`（复杂类）：完全覆写 `compute_raw` / `apply_cutoff` / `extra_info`。

## 6. 六大量表评分算法详解

> 以下“计分规则 / 界值”均取自 PDF 原始资料，并以 `scoring/config_data.py` 为准。

### 6.1 SCD-Q9（累加，0~9）

- 9 个条目；题 1/2/3/6/8/9 为二分项（`是=1 / 否=0`）；
  题 4/5/7 为频率项（`经常=1 / 偶尔=0.5 / 从未=0`）。
- **计分 = 各题得分累加**（无界值分级，`cutoffs=[]`）。
- 示例：全“是/经常” → 9 分；全“否/从未” → 0 分。

### 6.2 GDS-15（累加，0~15，含反序计分）

- 15 个“是/否”条目。
- **正序题**（是=1/否=0）：第 2,3,4,6,8,9,10,12,14,15 题。
- **反序题**（是=0/否=1）：第 1,5,7,11,13 题 —— 反序已内化到选项分值。
- 界值（LEVEL）：

| 总分 | 结果 | 是否异常 |
|---|---|---|
| 0–4 | 正常 | 否 |
| 5–8 | 轻度抑郁 | 否 |
| 9–11 | 中度抑郁 | 否 |
| 12–15 | 重度抑郁 | **是** |

### 6.3 FAQ（累加，0~30，含 NA）

- 10 个条目，每题 0~3 四级：
  `0=无困难`、`1=有些困难需指导`、`2=部分依赖`、`3=完全依赖`；
  `NA=该项目不适合/老人从来不做`（**不计入总分**）。
- **总分 = 非 NA 项得分之和**；NA 项仍被记录（score=0、option_code=NA），但不影响总分。
- 界值（LEVEL）：`0-5 正常`；`6-8 SCD 参考范围`；`9-30 MCI（轻度认知损害，异常）`。

### 6.4 MMSE（分项计分，0~30，教育界值）

- 30 个条目，每题 0/1（`正确=1 / 错误=0`），分 11 个认知域：

| 认知域 | 题数 | 满分 |
|---|---|---|
| 时间定向 | 5 | 5 |
| 地点定向 | 5 | 5 |
| 即刻记忆 | 3 | 3 |
| 注意与计算 | 5 | 5 |
| 延迟回忆 | 3 | 3 |
| 命名 | 2 | 2 |
| 复述 | 1 | 1 |
| 阅读理解 | 1 | 1 |
| 三步指令 | 3 | 3 |
| 书写 | 1 | 1 |
| 视空间 | 1 | 1 |

- **总分 = 各域得分之和**；`sub_scores` 按上述 11 域汇总。
- 教育界值（EDUCATION，按 `education_years` 匹配；`总分 ≤ 界值` 判异常）：

| 教育分组 | 受教育年限 | 界值 |
|---|---|---|
| 文盲 | 0 | 17 |
| 小学 | 1–6 | 20 |
| 中学及以上 | ≥7 | 24 |

### 6.5 MoCA-B（分项计分，0~30，教育界值）

- 24 个计分单元，涵盖执行功能、词语流畅性、定向、计算、抽象、延迟回忆、
  视知觉、命名、注意等认知域；合计 30 分：

| 分项 | 题号（计分单元） | 计分 | 满分 |
|---|---|---|---|
| 执行功能（连线） | 1 | 完全按序=1 / 有错=0 | 1 |
| 词语流畅性 | 1 | ≥13=2 / 8-12=1 / ≤7=0 | 2 |
| 定向 | 6 | 各 0/1 | 6 |
| 计算 | 1 | 3 种=3 / 2 种=2 / 1 种=1 / 0=0 | 3 |
| 抽象 | 3 | 各 0/1（橘子香蕉为**练习不计分**） | 3 |
| 延迟回忆 | 5 | 各 0/1 | 5 |
| 视知觉 | 1 | 9-10 个=3 / 6-8=2 / 4-5=1 / ≤3=0 | 3 |
| 命名 | 4 | 各 0/1 | 4 |
| 注意（白底） | 1 | 全对或 1 错=1 / 2 错以上=0 | 1 |
| 注意（黑底） | 1 | ≤2 错=2 / 3 错=1 / ≥4 错=0 | 2 |

- 教育界值（EDUCATION；`总分 ≤ 界值` 判异常）：

| 教育分组 | 受教育年限 | 界值 |
|---|---|---|
| 文盲/小学 | ≤6 | 19 |
| 中学 | 7–12 | 22 |
| 大学 | ≥13 | 24 |

### 6.6 CDR（复杂评分，Morris 规则）

6 个功能域各记 `0 / 0.5 / 1 / 2 / 3` 分：

| 功能域 | 角色 |
|---|---|
| 记忆力（`CDR_MEMORY`） | **主要项目（M）** |
| 定向力 | 次要 |
| 判断与解决问题 | 次要 |
| 社会事务 | 次要 |
| 家务与业余爱好 | 次要 |
| 个人自理 | 次要 |

#### 整体 CDR 算法（Morris, 1993）

以记忆力 **M** 为主要项目，其余 5 项为次要项目（记为集合 S）：

1. **M=0**：若 S 中 ≥2 项 ≥0.5，则 CDR=0.5；否则 CDR=0。
2. **M=0.5**：若 S 中 ≥3 项 ≥1，则 CDR=1；否则 CDR=0.5（CDR 不能为 0）。
3. **M≥1**，依次判定：
   - **3.1** 至少 3 个次要项 = M → CDR = M；
   - **3.2** 仅 1–2 个次要项 = M，且两侧（>M 与 <M）各不多于 2 个 → CDR = M；
   - **3.3** 3 个次要项在 M 一侧、另 2 个在另一侧 → CDR = M；
   - **4.4** 至少 3 个次要项 = 0 → CDR = 0.5；
   - **4.1** 至少 3 个次要项 > M 或 < M → CDR = 多数次要项分数
     （并列时取**与 M 最接近**者）；
   - **5（就近联合）** 以上皆不满足 → CDR = 与 M 最接近的次要项分数。

> 注：在上述规则顺序下，“就近联合”作为多数规则的并列裁决出现（见示例 3），
> 其独立分支与多数规则的“并列取近”语义一致，结果等价。

#### CDR 分级解释

| 整体 CDR | 结果 |
|---|---|
| 0 | 无痴呆（CDR=0） |
| 0.5 | 可疑痴呆（CDR=0.5） |
| 1 | 轻度痴呆（CDR=1） |
| 2 | 中度痴呆（CDR=2） |
| 3 | 重度痴呆（CDR=3） |

- **异常判定**：整体 CDR > 0 即异常。
- **CDR-SB** = 6 个功能域得分之和（0~18），存入 `extra["cdr_sb"]`。

#### 判定示例

| M | 次要项目 S | 命中的规则 | 整体 CDR |
|---|---|---|---|
| 0 | [0,0,0,0,0] | 1（<2 个 ≥0.5） | 0 |
| 0.5 | [1,1,1,0,0] | 2（≥3 个 ≥1） | 1 |
| 1 | [1,1,1,0,0] | 3.1（≥3 个 =1） | 1 |
| 1 | [1,1,2,0.5,0.5] | 3.2（2 个 =1，两侧 ≤2） | 1 |
| 1 | [2,2,2,0.5,0.5] | 3.3（3 个 >，2 个 <） | 1 |
| 1 | [1,0,0,0,0] | 4.4（≥3 个 =0） | 0.5 |
| 1 | [2,2,2,2,0.5] | 4.1（多数 2） | 2 |
| 3 | [3,2,2,1,1] | 4.1（众数 2 与 1 并列，取近 M=3 的 2） | 2 |

完整分支覆盖见 [`tests/test_cdr_algorithm.py`](../tests/test_cdr_algorithm.py)。

## 10. 关键假设与说明

1. **教育年限 → 分组映射**：PDF 仅给出分组名，未给具体年段。
   采用通用映射并已在文档中注明：
   - MMSE：文盲=0 年、小学=1–6 年、中学及以上 ≥7 年；
   - MoCA-B：文盲/小学 ≤6 年、中学=7–12 年、大学 ≥13 年。
2. **异常判定规则**：MMSE / MoCA-B 以 `总分 ≤ 界值` 判异常
   （MoCA-B PDF 明确“小于等于节点为异常”，MMSE 沿用同规则）。
3. **FAQ 的 NA 项**不计入总分（跳过）。
4. **`6.ADAS-cog.pdf`** 不在本次 6 量表范围内，暂不实现。
5. **表结构**采用「5 核心表 + 3 支撑表」；支撑表（题目/选项/界值）用于承载配置数据，
   满足“录入全部配置数据到数据库”的要求。
6. **密码**：演示数据中的 `password_hash` 为占位符，正式环境请用安全哈希（如 bcrypt）。
